## Changes
- PHP 7.4 compat: `web_root` computation in `Plugin.md` §3 now uses
  `0 === strpos( $css_dir . '/', ABSPATH )` instead of the PHP 8+
  `str_starts_with()`.
- Pinned `CompiledResult::$fileName` (§4) as the CSS output path relative to
  `css_dir` (e.g. `main.css`, `modules/card.css`) — the `Writer::mirrorPath()`
  result.
- Clarified fingerprint semantics (§5): `Scanner::fingerprint()` returns one
  whole-directory md5 over every `.scss` file (partials included); the same
  value is stored under every entry key, so any change recompiles all entries.
  Added the matching note to the auto-mode glue about refreshing the stored map.
- Pinned the endpoint URL format for `web_root === false` (§6): the relative
  path is `rawurlencode()`d (`/` → `%2F`) to satisfy the single-segment rule,
  and the handler `rawurldecode()`s the query var before `realpath()`.

### Tooling decisions (approved by user)
- `src/` and `tests/` are a WordPress-agnostic PSR-4 library that may not call
  `wp_*` (Plugin.md contract), so WPCS naming and WP-only-idiom sniffs are
  lifted for those paths in `.phpcs.xml.dist`:
  `WordPress.NamingConventions.Valid{FunctionName,VariableName}`,
  `WordPress.WP.AlternativeFunctions`, `WordPress.PHP.NoSilencedErrors`,
  `Universal.Arrays.DisallowShortArraySyntax`.
- `PHPStan` level max: enabled by proper types (typed properties on value
  objects and tests, `@param`/`@return` array generics) and a shared private
  `splFileInfoIterator()` generator (typed `SplFileInfo`) in `Scanner` and
  `Enqueue` replacing raw `RecursiveIteratorIterator` foreach.
- `tests/integration/*` extend `WP_UnitTestCase` (wp-env only); they are
  excluded from PHPStan (`szepeviktor/phpstan-wordpress` ships no
  `WP_UnitTestCase` stub), so `phpstan.neon.dist` analyzes `src/` +
  `tests/unit/` only.
- `BE_PLUS_SCSS_COMPILER_MAIN_FILE` is defined by the main file, so PHPStan
  loads it via `phpstan-bootstrap.php` (`bootstrapFiles` in
  `phpstan.neon.dist`).
- `composer analyse` runs with `--memory-limit=512M` (the default 128M OOMs on
  the new Plugin/SettingsPage surface with level max + the WP stubs).
- Added `readme.txt` and `languages/beplus-scss.pot` (20 strings, all
  `beplus-scss` textdomain occurrences from the codebase).
